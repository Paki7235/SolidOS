# Primi passi

Benvenuto in **{{OS_NAME}}**: il sistema che non si rompe, non rallenta e ricorda tutto.

## Le scorciatoie più utili

| Tasti | Cosa fa |
|---|---|
| **Super + Spazio** | Barra Unica: cerca app, file, impostazioni e fai azioni («wifi off», «installa vlc») |
| **Super + A** | Centro di controllo: Wi-Fi, Bluetooth, volume, luminosità, Non disturbare |
| **Super + N** | Centro notifiche |
| **Super + E** | File |
| **Super + I** | Impostazioni |
| **Super + T** | Linea del Tempo |
| **Super + L** | Blocca lo schermo |
| **Alt + Tab** | Cambia finestra |
| **Super + ← / →** | Affianca la finestra a sinistra o a destra |
| **Stamp** | Cattura lo schermo (Maiusc + Stamp per più opzioni) |
| **Ctrl + Maiusc + Esc** | Monitor di sistema |

Il tasto **Super** è quello con il simbolo, tra Ctrl e Alt.

## Dove trovo le cose

- Il **menu** è il logo in basso a sinistra.
- Le **app aperte** sono nella barra in basso.
- Accanto all'orologio trovi il **centro di controllo** e le **notifiche**.
