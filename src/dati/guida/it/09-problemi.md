# Se qualcosa non va

| Problema | Soluzione |
|---|---|
| Il computer non si avvia dopo un aggiornamento | All'accensione scegli **Torna a ieri** |
| Schermo nero all'avvio della chiavetta | Scegli **Prova {{OS_NAME}} (grafica sicura)** |
| Il computer è lento | Impostazioni → Informazioni e Benvenuto: attiva il profilo «PC vecchio»; apri il Monitor di sistema (Ctrl + Maiusc + Esc) |
| Un file è stato sovrascritto o cancellato | Linea del Tempo (Super + T) |
| Il disco dell'altro sistema si apre solo in lettura | L'altro sistema è in ibernazione: avvialo e spegnilo tenendo premuto Maiusc mentre clicchi «Arresta» |
| Il telefono non vede il computer | Attiva Condivisione Vicina dal centro di controllo; stessa rete Wi-Fi; prova il codice QR |
| Il telefono non vede il computer | Usa il codice QR in Condivisione Vicina: si inquadra con la fotocamera |
| Un programma di un altro sistema non funziona | Non tutti funzionano con Wine: cerca un'alternativa nello store |
