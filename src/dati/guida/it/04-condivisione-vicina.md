# Condivisione Vicina

Invia e ricevi file con **telefoni Android, iPhone, iPad, Mac e altri computer**.

## Inviare

Clic destro su uno o più file → **Condividi con dispositivi vicini**. Scegli il dispositivo oppure la scheda **Codice QR**.

## Ricevere

Apri **Condivisione Vicina** dal menu S (o dal centro di controllo, Super + A): il computer è visibile a tutti per 10 minuti. Quando qualcuno ti invia un file compare una richiesta con **Accetta** o **Rifiuta**: nulla viene ricevuto senza il tuo consenso. I file arrivano in *Scaricati/Ricevuti*.

## Con quale dispositivo funziona

| Dispositivo | Come | Note |
|---|---|---|
| **Android** | dal menu Condividi → **Quick Share** | telefono e computer sulla stessa rete Wi-Fi; per ricevere dal PC il telefono deve essere visibile a «Tutti» |
| **iPhone, iPad** | **codice QR** con la fotocamera, oppure l'app LocalSend | nessuna installazione necessaria con il codice QR |
| **Qualsiasi dispositivo con LocalSend** | app gratuita LocalSend | funziona ovunque, anche su iPhone |
| **Qualsiasi telefono** | **codice QR** | non serve installare nulla: inquadri il codice e usi il browser |

## Senza Wi-Fi in comune

Nella scheda QR premi **Crea un hotspot**: il primo codice collega il telefono alla rete del computer, il secondo apre la pagina di scambio.
